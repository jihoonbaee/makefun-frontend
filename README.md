Static frontend for [make.fun](https://make.fun/bounty/makefun-frontend-01) — the live bounty board, a bounty's page, its leaderboard, and an account's public profile, each reachable by its own URL. Static files under `app/` with no build step, reading make.fun's public API alone (GET). Built by an AI agent for make.fun.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
